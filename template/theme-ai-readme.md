# 让 AI 帮你做导航站主题：零基础也能开发六零导航页主题

> 本文介绍如何用一份「AI 主题生成提示词」，把你的审美直接变成六零导航页（lylme spage）可上线的主题。无需精通 PHP、CSS、JS，只要会描述你想要的风格。

---

## 一、想做主题，却一直没动手？

很多站长用六零导航页搭好了自己的导航站，但默认主题看久了总觉得「差点意思」：配色不是心头好、布局不够顺眼、想要点自己的个性。

于是你动了「自己做一个主题」的念头。可是打开开发文档一看——PHP 语法、CSS 变量、搜索引擎 DOM 契约、移动端断点、图标雪碧图依赖……一大堆细节直接把人劝退。

过去这确实是门槛：你要既懂设计、又懂代码，还得踩得平各种兼容坑。但现在，这件事可以交给 AI 来做。

---

## 二、AI + 官方开发包 = 人人都能做主题

六零导航页官方提供了一套 `dev-theme` 开发包（template/dev-theme目录）。它的设计原则是「轻量、单文件、零框架」：复制目录、改名、改 CSS，就能开搞。

我们基于这套开发包，把全部技术规范固化成了一份**「AI 主题生成提示词」**。它的作用是：

- 把开发文档里的硬性规则（兼容性、安全转义、必须保留的代码、接口契约）**写死在提示词里**，AI 生成时不会乱来；
- 预留一个**「风格输入区」**，由你来决定主题长什么样；
- 指挥 AI 一次性产出一套完整、可启用的主题文件。

换句话说，你负责「想」，AI 负责「写」。

---

## 三、三步上手：怎么用这份提示词

**第一步：填写风格输入区**

打开提示词，找到「一、风格输入区」，把你想要的风格填进去。比如：

```
主题名称：moonlight
风格关键词：极简、暗色、毛玻璃
主色：#6c8cff
氛围：冷静、专业、夜晚感
布局：卡片网格、圆角
字体：圆润无衬线
动效：悬停轻微放大
默认：暗色
```

如果你懒得想，也可以直接留空，AI 会自行补全一套协调的设计。

**第二步：投喂给 AI 工具**

把整份提示词（含你填好的风格）发给任意 AI 编程助手（如 WorkBuddy、ChatGPT、Claude、通义灵码等）。它会返回 7 个文件的完整代码：

```
你的主题目录/
├── index.php        # 页面入口
├── theme.ini        # 主题信息
├── config.php       # 后台可配置项
├── functions.php    # 辅助函数库
├── css/style.css    # 样式
├── js/script.js     # 脚本
└── README.md        # 说明文档
```

**第三步：放进去，启用**

把生成的目录拷贝到程序的 `template/` 下，到后台「系统设置 - 网站主题」里切换到你的主题即可。想微调？在「主题设置」里改主色、列表列数、首页公告、备案号就行，不用碰代码。

## 四、「风格输入区」：你的创意决定长相

这是整个流程里最有意思的部分。提示词暴露的可填写项包括：

- **主题名称**（小写英文，作为目录名）
- **风格关键词**（极简 / 玻璃拟态 / 赛博朋克 / 复古 / 自然 / 二次元……）
- **主色与配色方案**（可以给具体色值）
- **整体氛围**（冷静专业 / 温暖治愈 / 科技未来 / 活泼可爱）
- **布局偏好**（卡片网格 / 瀑布流 / 全屏居中 / 左侧栏 / 圆形图标）
- **字体偏好**（圆润 / 纤细 / 等宽 / 衬线）
- **特殊视觉元素或动效**（毛玻璃、霓虹描边、悬浮放大、渐变背景、滚动视差）
- **明暗模式**（默认暗色 / 亮色 / 跟随系统）

几个随手就能用的风格示例：

- 「极简暗色 + 毛玻璃卡片 + 圆润字体」—— 适合个人极客站；
- 「赛博朋克 + 霓虹描边 + 渐变背景」—— 适合二次元、资源站；
- 「温暖奶油色 + 大圆角 + 悬浮动效」—— 适合生活、工具导航。

## 五、AI 不会乱来：内置硬约束兜底

很多人担心「AI 写的代码能直接用吗？」这份提示词在技术规范上做了强制约束，确保产出的主题可用、合规：

- **兼容性**：PHP 代码统一 `array()` 写法，禁用 PHP 7+ 专有语法，兼容 5.4 / 7.x / 8.x；JS 用 ES5，不使用 `let`/`const`/箭头函数。
- **安全输出**：所有文本输出经转义函数处理，避免 XSS；图标等官方 HTML 原样保留。
- **必须保留的契约**：统计代码 `wztj`、图标雪碧图 `icon.js` 和旧版图标雪碧图 `svg.js`三处硬性依赖一字不差，否则站点图标会空白。
- **移动端友好**：保留 768px 断点，手机端链接列表自动降为 2 列。
- **发布自检清单**：AI 生成后会逐条核对，目录名与主题名对应、JSON 合法、版本号三段式等。

## 六、从「做出来」到「用起来」

主题做好并启用后，你还能在后台做轻量定制：

- 改**主色**让按钮、链接悬停更贴合品牌；
- 调**列表列数**（3~6 列）控制信息密度；
- 填**首页公告**（支持 HTML）做活动提示；
- 填**公安备案号**，底部自动生成备案链接。
