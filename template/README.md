## 六零导航页主题目录

#### 目录内容

| 目录 | 说明 |
| ---- | ---- |
| `dev-theme/` | 官方开发包（规范示范主题，零框架依赖、单文件入口） |
| `default/`、`lylme/` 等 | 现有主题 |

现有主题均早于本规范，结构不完全一致；新主题请以 `dev-theme` 与 `dev.md` 为准。


#### 主题开发文档

- [官方云文档](http://doc.lylme.com/dev/theme)

- [本地文档](./theme-dev.md)

> 开发包结构、辅助函数、数据接口、页面结构标准、自检清单

#### 主题开发包

- **本地目录：**[dev-theme目录](./dev-theme)：脚手架主题，复制改名即可开始开发
- **云端下载：**[dev-theme.zip](https://cdn.lylme.com/lylme_spage/themes/dev-theme.zip)：与本地一致，若丢失可在此处下载
